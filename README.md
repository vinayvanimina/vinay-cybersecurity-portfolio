## Local preview
Open `index.html` directly in your browser, or run a simple local server:

```bash
python -m http.server 8080
```

Then open:
`http://localhost:8080`

## Cloudflare Pages
Upload this folder to GitHub and connect the repository to Cloudflare Pages.
For this static site, no build command is required.
Use the project root as the output directory.

Suggested custom domain:
`portfolio.cyberfox.in`
