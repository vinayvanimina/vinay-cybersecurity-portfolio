READ-ONLY BY DESIGN

MCP investigation path

Six bounded tools retrieve approved Wazuh health, agent, rule, alert and vulnerability information. They cannot enroll agents, change configurations, write to indexes or trigger responses.

CONTROLLED INTAKE

Sanitized alert path

Only high-severity lab alerts pass through a fixed allowlist. The workflow keeps the IRIS API key in protected storage and creates alerts—not cases or endpoint actions.

PERSISTENT SERVICES

Reboot-safe lab stack

Wazuh MCP, Wazuh services, Shuffle, DFIR-IRIS and the private relay are configured to recover after normal service or host restarts.

VALIDATION

End-to-end alert automation confirmed.
