# Project Archive

This folder is the source of truth for Vinay Kumar Vanimina's hands-on cybersecurity and infrastructure projects.

The goal is to keep both current and past work documented in a consistent, recruiter-friendly format without exposing customer-sensitive information.

## Documentation Standard

Every project should capture:

- Objective
- Problem / use case
- Architecture
- Technologies used
- Implementation approach
- Security considerations
- Challenges and troubleshooting
- Outcome
- Lessons learned
- Future improvements
- Sanitization notes

Use [`TEMPLATE.md`](TEMPLATE.md) for every new project.
